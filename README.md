# Supa Maket starter

## Requirements
- Node.js 20.9 or newer
- Visual Studio Code (recommended)

## Run locally
1. Open this folder in VS Code.
2. Open Terminal > New Terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

## Important
This is a front-end starter with sample listings and browser-only interactions. It does not yet have shared accounts, a database, live availability, real bookings, or payments.

## Photos
Place your four chosen photos in `public/images/` with these exact names:
- `home.jpg` — final photo for home page
- `bnbs.jpg` — first photo for BnBs
- `car-hire.jpg` — second photo for car hire
- `shopping.jpg` — third photo for shopping

If your photos are PNG or WEBP, either convert them to JPG or update the matching file extension in `app/globals.css`.
